# Naming Conventions

- Folders: kebab-case, no spaces (e.g. `startup-ideas`)
- Dated notes: `YYYY-MM-DD-topic.md`
- ADRs/decisions: `ADR-0001-short-title.md`, sequential per scope
- Templates: `template-<name>.md`
- Context files: always exactly `CLAUDE.md`
- Status files: fixed name per scope — `STATUS.md`, `ROADMAP.md`
- Skills: folder = skill name (kebab-case), contains `SKILL.md`
- No version numbers or "final" in filenames — git handles versioning
