# Contributing

ClaudeOS is a template, not a shared knowledge base — there's nothing to
"contribute data" to. Contributions here mean improving the *system itself*:

- Better conventions in `00-System/conventions/`
- A clearer or more general playbook in `00-System/playbooks/`
- A useful example Skill under `05-Evergreen/Skills/` (generic, no company/
  personal data)
- README/setup clarity, especially around Claude Code / Cowork / Notion /
  Obsidian setup steps that trip people up

## How to propose a change

1. Fork the repo, branch off `main`
2. Keep changes to the *structure and documentation* — don't add real
   company, career, or personal content anywhere in the tree
3. Open a PR describing what you changed and why (what broke, what was
   unclear, what pattern you found worked better)

## Ground rule

Nothing merged here should ever contain anyone's real identity, company,
Notion IDs, credentials, or personal data — including in commit history. If
you're not sure, ask in the PR before pushing.
