# Memory — Stable Identity Layer

Small, stable, read every session. Not a knowledge dump — see `05-Evergreen/`
for that.

## Files

- `identity.md` — who you are, roles, background
- `preferences.md` — how Claude should work with you
- `decisions-global.md` — major cross-company/life decisions
- `notion-map.md` — where things live in Notion, if you use it; check here
  before concluding ClaudeOS doesn't have an answer
- `relationships.md` — key people (optional)

## Editing anything here

Keep this folder small — it's loaded at the start of every session, so bloat
here is the most expensive kind of bloat in the whole system. If you maintain
a Notion mobile mirror (see `00-System/conventions/notion-integration.md`),
this is the folder that mirror is generated from.
