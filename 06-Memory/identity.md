# Identity

Replace every line below with your own — this is the highest-leverage file in
the whole repo because it's loaded every session. Keep it factual and stable;
things that change often belong in `decisions-global.md` or a scope's own
`CLAUDE.md`, not here.

- Role / title, company, one line on what you're building
- Background — the 2-3 things that explain how you think about problems
  (industry, prior experience, domain expertise)
- Technical stack, if relevant to how Claude should help you
- Long-term vision / what you're optimizing for over the next 1-3 years

**Example (fictional):**

- Founder, Northwind Labs — building workflow automation for logistics SMBs
- 8 years in backend/infra before founding; ex-payments engineer
- Stack: Python, Postgres, AWS, Terraform
- Vision: become the default ops layer for mid-market freight brokers
